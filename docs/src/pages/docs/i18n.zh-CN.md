组件内置文案默认是简体中文，通过 `ConfigProvider` 的 `locale` 切换语言，用法与 PC 端相同。

```vue
<script setup lang="ts">
import enUS from '@antdv-next/mobile/locale/en_US'
</script>

<template>
  <am-config-provider :locale="enUS">
    <App />
  </am-config-provider>
</template>
```

## 内置语言包 {#locales}

| 语言 | 文件 |
| --- | --- |
| 简体中文 | `@antdv-next/mobile/locale/zh_CN` |
| English | `@antdv-next/mobile/locale/en_US` |

## 静态方法 {#static}

`Modal.confirm`、`Toast` 等静态方法不在组件树中，使用 `ConfigProvider.config` 设置：

```ts
import { ConfigProvider } from '@antdv-next/mobile'
import enUS from '@antdv-next/mobile/locale/en_US'

ConfigProvider.config({ locale: enUS })
```

## 自定义语言包 {#custom}

语言包是一个普通对象，可以基于内置语言包扩展：

```ts
import type { Locale } from '@antdv-next/mobile'
import zhCN from '@antdv-next/mobile/locale/zh_CN'

const zhTW: Locale = {
  ...zhCN,
  locale: 'zh-tw',
  common: { ...zhCN.common, confirm: '確定', cancel: '取消' },
}
```

日期类组件使用 dayjs，记得同时切换 dayjs 的语言：

```ts
import dayjs from 'dayjs'
import 'dayjs/locale/en'

dayjs.locale('en')
```

## 在自己的组件里使用 {#use-locale}

```ts
import { useLocale } from '@antdv-next/mobile'

const locale = useLocale('Modal')
locale.value.okText // '确定'
```
